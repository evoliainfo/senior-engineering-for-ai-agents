# SEF v1.4.0-beta — Web Discoverability & Measurement Engineering

SEF v1.4 extends the Project Engineering OS beyond application engineering into public-web discoverability and measurement while preserving the existing governance baseline.

## Added

Three task-scoped execution playbooks:

- **SEO & Web Discoverability Engineering**
- **GEO / AI Discoverability Engineering**
- **Analytics & Conversion Instrumentation**

SEF now contains **8 execution playbooks**, while the governance catalog remains **538 controls across 17 specialist packs**.

## Why this release

A public website can be technically functional while still shipping with accidental `noindex`, broken canonicals, weak crawl paths, unverifiable structured data, unreliable analytics or untested conversion semantics. v1.4 lets SEF infer and route those engineering concerns without requiring a non-expert user to name them in advance.

The routing remains proportional: a CSS-only website edit stays lightweight, while public-site creation, lead-generation, SEO/GEO work or analytics instrumentation activates the relevant procedures.

## Evidence model

v1.4 deliberately avoids outcome inflation:

- technical SEO readiness is not proof of indexation or ranking;
- AI crawler readiness is not proof of citation or placement;
- an analytics tag firing is not proof of ingestion or a valid business conversion;
- provider-specific behavior must be re-checked against current primary documentation.
